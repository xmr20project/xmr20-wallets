# XMR20 Wallets

The XMR20 wallets in one place: the shared engine, the terminal wallet (CLI), the Chrome extension and the xmr20.org
website wallet.

The first content is being reviewed in an open pull request. Until it is merged, the wallets live in the main project
repository, https://github.com/xmr20project/XMR20.

Experimental software on mainnet. It has not had an independent security review.
